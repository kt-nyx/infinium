## Practical outcome

C1 closes the non-live gap between accepted R2 behavior and a future,
separately authorized C2 campaign. Infinium now has one typed runtime-authority
contract, exact candidate/binary/path/predecessor/ceiling validation, and a
hash-chained durable campaign binding at the credential and provider-stage
admission points. The executable credential and provider wrappers consume that
typed manifest plus durable state. They do not inspect Git branch, HEAD,
history, commit messages, record markers, pickaxe, or attribution to discover

an API key, active campaign, credential authorization, stage request or
admission, production profile, real-campaign safety-use latch, provider effect,
or billable evidence.
