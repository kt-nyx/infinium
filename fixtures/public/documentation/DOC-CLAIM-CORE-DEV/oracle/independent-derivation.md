# Independent derivation — DOC-CLAIM-CORE-DEV

The answer-bearing values in this package were authored before any product comparison. The oracle author did not inspect or execute the documentation importer and did not use product output.

Offsets and passage hashes were derived directly from the checked-in UTF-8 source bytes. Stable identities were calculated independently from the public documentation stage identity rule: each outer ordered string is encoded as a four-byte signed big-endian UTF-8 byte length followed by its UTF-8 bytes; SHA-256 is computed over the concatenation and the first 32 lowercase hexadecimal characters are appended to the artifact prefix. Canonical sets are ordinal-sorted and encoded as concatenated decimal UTF-8 byte length, a colon, and the literal value. Ordered descriptors use that same decimal framing without sorting.

Claim bases bind the producing import and deterministic claim fields. Final claims bind the base identity, canonical direct contradiction-target base IDs, and canonical descriptors for every reachable contradiction node, traversed cycle-safely with the root previsited. Each reachable-node descriptor binds that node base ID and its canonical direct-target base-ID set. Applications bind the exact emitted evidence set: the primary claim plus resolved supporting claims, distinct and ordinal-sorted. The case matrix separately fixes every accepted application target, including installation snapshot and resolved input manifest. Purpose and gap identities bind their complete semantic fields, including the canonical fixture timestamp and exact reason.

The aggregate evidence identity binds schema ID/version and originating run plus ordered, decimal-framed lists of full serialized revision, current-import, passage, claim, application, purpose, deletion-receipt, gap, and failure descriptors. Lists preserve the frozen output order: stable-ID ordinal order for these objects and the explicitly frozen boundary/nested-set orders. Every descriptor binds every serialized DTO field in its public contract order, including exact boundary reasons, passage state, claim prose/conditions/contradictions, complete application evidence, and exact reason/timestamp fields. Descriptors are literal UTF-8 text, not hexadecimal or Base64; only the outer stable-ID arguments use four-byte big-endian framing.

The source deliberately uses `é`, `Ω`, and an em dash before the first claim terminates so character offsets cannot accidentally pass as UTF-8 byte offsets. The installation and priority claims deliberately share one exact passage. Expected purpose truth comes only from the explicit declared-purpose claim and application declaration.

The independent calculator was an ephemeral, product-free PowerShell routine using only .NET UTF-8, SHA-256, and big-endian integer primitives. No generator is retained in this fixture.
